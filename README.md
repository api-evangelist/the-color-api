## APIs

### The Color API

Free, public REST API providing color information for any input color. Returns all color format conversions (hex, RGB, HSL, HSV, CMYK, XYZ), nearest named color, placeholder image URLs, contrast color, and harmonious color schemes based on color-wheel relationships. No authentication required.

- **Human URL:** [https://www.thecolorapi.com/](https://www.thecolorapi.com/)
- **Base URL:** `https://www.thecolorapi.com`
